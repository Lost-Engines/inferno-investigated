The routes beneath the scenery

Inside the corridors

Behind the tunnels is a second structure: paths for navigation and a volume that keeps the craft inside. The game stores 64 of these patterns separately from the visible scenery. Amber lines show paths; cyan outlines show the containment radius or room bounds.

Drag to orbit, Shift-drag to pan, wheel to zoom. Turn surfaces off to see the complete path through the walls. Some pieces draw only from a room or a tunnel; Automatic chooses a visible context.

Click a point to test it. Y increases downward.

Directed routes

Each path has a reverse partner. Collision tests visit one path from each pair; actors can travel in either direction.

World locations
The coloured outlines are our guide to the space the game allows a craft to occupy. In rooms, the paths guide actors while the outer box defines the permitted space.
