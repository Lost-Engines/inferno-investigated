How this view works

This viewer runs the decoded model drawing commands with a movable inspection camera. Animation badges mark models with state controls; vertex motion marks moving vertices. Thumbnails use a visible state from the model’s drawing program. Automatic palettes use justsun1 for general models, the intro colours for the textured planets and the matching orbital colours for planet backdrops. Choose a palette to compare lighting across the collection.
